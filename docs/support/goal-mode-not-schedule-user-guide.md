# 目标模式被做成定时任务？这样用就对了

## 先分清三件事

| 你想要 | 请用 | 不要用 |
|--------|------|--------|
| 从现在起按某套原则陪你做事 | **项目/会话规则**（或第一条消息贴原则） | 已安排、每天循环 |
| 把一件事**连续做完** | **Goal（目标任务）** 或普通多轮对话 | 定时任务 |
| 到点 / 每隔一段时间自动再跑 | **已安排** 或说明「每天几点 / 每 N 分钟」 | Goal 长文角色卡 |

**口诀：原则 = 说明书 · Goal = 任务单（干完即停）· 定时 = 闹钟**

---

## 常见误区

容易变成定时任务的做法：

- 说「开启目标模式」+ 整篇「始终 / 每次 / 维护…」长文  
- 只有「一直帮我优化」，没有「做到什么算完成」  
- 打开 Goal 后，把角色说明书当成唯一一条消息发出  

---

## 推荐用法

### 1）只要长期原则

把原则放进项目规则，或会话开头贴一次，并加上：

```text
【执行约束】
- 这是会话原则，不是定时任务。
- 禁止创建 /loop、scheduler、已安排、自动化。
- 有具体改动时在本会话连续做到可验收，不要用闹钟续跑。
```

### 2）本轮要干完一件事（推荐用 Goal）

写成「做什么 + 怎样算完成」，例如：

```text
/goal 收敛主线：点燃 → 进厅 → 主线 3 洞可闭环。
成功标准：能口述这三步；同屏只有一个主动作；支线不抢开场。
禁止创建任何定时任务或已安排。做完对照标准说明如何验收。
```

原则已在规则里时，Goal 里**只写本轮交付**，不必每次贴全文。

### 3）真的需要定时

直接说清时间，例如：「每天 09:00 检查线上主线是否回归」。  
或用侧栏 **已安排** 创建。成功时应看到「定时 / 已安排」，不是「目标模式已开」。

---

## 已经变成定时任务时

1. 打开侧栏 **「已安排」** → 暂停或删除该任务  
2. 回到对话，按上面 **§推荐用法** 重开（原则用规则，任务用 Goal，并写禁止定时）  
3. 接着干活时发**短目标 + 验收**，不要再贴「始终维护」长文当 Goal  

---

## 发送前 10 秒自检

- [ ] 写了「每天 / 每小时 / 点钟 / 定期」？→ 才会走定时  
- [ ] 写了「完成标准 / 验收 / 做完即停」？→ 适合 Goal  
- [ ] 只是「以后都按这套想」？→ 用规则，不要 Goal、不要定时  
- [ ] 开放维护类是否写了「禁止已安排 / loop」？  
- [ ] 若出现「已安排 / 定时任务」提示 → 按上一节撤销，不要当成功  

---

## 可贴群的三句话

```text
1) 产品原则 / 角色 → 规则（一直生效，不是任务）
2) 本轮要干完 → Goal 或连续对话（干完即停）
3) 到点或周期性 → 已安排（闹钟）
「开启目标模式」+「始终维护」长文，最容易被做成 3)。
```
