## 1. 产品原则（GUI ↔ CLI 1.0）

### P1 — Wrap CLI，不重做 TUI

- 智能路径: **Host `AcpClient` → `grok … agent … stdio` / headless `grok -p`**。
- GUI 负责: 多会话池、journal、composer chrome、settings IA、导出包装、诚实空态。
- **禁止发明:** 无 `goal_updated` 的进度条、无 CLI 信号的 dream running、仅靠 socket 的 fleet metrics、无 host 路径的 hybrid memory 搜索。

### P2 — CLI 为能力与默认的 Source of Truth

| 层 | SoT |
|----|-----|
| 模型 / effort 默认 / context | `models_cache` + ACP `initialize` meta |
| permission / sandbox / tools | spawn flags + independent `config.toml` |
| memory / workflows / privacy keys | `GROK_HOME`（independent 可写；shared 只读） |
| soft-gate | 探测版本；未知 → 省略非默认 flag（防 clap 崩） |

`src/lib/grokCatalog.ts` 静态表仅 **冷启动兜底**，有 live catalog 时不得压过 CLI。

### P3 — Apply-path honesty

每个会改变 agent 行为的控件声明生效路径:  
`next_message` · `immediate_rpc` · `soft_respawn` · `settings_spawn` · `host_only` · `soft_omit`  
（既有 `modelEffortApply` / `partialStreamHonesty` 等模式延续）。

### P4 — Soft-fail 旧 CLI；1.0 为推荐线

- 硬门槛保持 **0.2.112**（或单独决策后再抬）。
- 功能门保持 **0.2.117** 语义。
- UI 可写「推荐 1.0+」，**不得**硬挡 0.2.117 用户。

### P5 — Independent agent-home 默认；shared 显式

- Independent: 可写 agent-home 的 allowlisted keys。
- Shared: **禁止**为「方便」改写用户 `~/.grok`。

### P6 — 架构冻结

- 禁止在 `App.tsx` 新增 `useState` / 大块功能；新状态进 `providers/` · `hooks/` · 领域组件。
- i18n en/zh/zh-TW；`settingsCatalog` 登记；dialogs 规范。

### P7 — 先挖深已有模块，再新开面

优先加深:  
`AgentTasksPanel*` · `AgentDashboardModal` · `SessionTaskBoardModal` · `goalOrch` · Reliability · `SandboxWizard` · Memory ops · `ProjectInspectPanel` · `AgentsPersonasConsolePanel` · `WorkflowsSettingsBlock` · export / `grok export`。

## 2. 默认行为对齐矩阵

| CLI 1.0 默认 / 事实 | App 今天 | 目标 | 动作 |
|---------------------|----------|------|------|
| Model **grok-4.5** | 兜底一致 | 不变 | live list 优先 |
| Context **500K** | live-merge；custom 200K | 官方芯片显示 live 500K | 验证 initialize；禁止官方路径用 200K |
| Effort 默认 **high** | static **medium** | **catalog `isDefault` → high**；static 冷启动也 high | A1 见下 |
| Spawn effort id | 仅 low/medium/high | **透传 catalog spawnId**（含 max 等） | 修 `acp_client` 白名单 |
| Background wait | `wait` | 保持 | 与 CLI 默认一致 |
| Partial messages | off | 保持 | headless 专用 |
| Sandbox | App **workspace** | **保持**（产品安全） | 文案标明 App 推荐 ≠ CLI off |
| Permission | `ask` → CLI `default` | 保持 | — |
| Session mode | `agent` | 保持 | — |
| Plan | `plan_enabled: true` | 保持 | — |
| Subagents | on | 保持 | — |
| Workflows | App **off** / CLI **on** | **对齐 on（independent 新装/迁移）** | 见决策 D-W |
| Memory experimental | App **off** + `--no-memory` | **保持 off**（隐私） | 产品化 dream/clear，不默认开 |
| Auto-wake | off | 保持 opt-in | — |
| Leader | off → `--no-leader` | 保持 | 高级入口 |
| Compaction | summary / verbose | 保持 | soft-gate flags |
| Session data mode | independent | 保持 | — |
| Soft-gate 文案 | 「0.2.117+」 | 保留门槛数；补充「1.0 verified」 | 文案 hygiene |
| Binary | 只 `grok` | Doctor 检测 `agent` symlink skew | 修复 symlink 动作 |

### 决策 D-E — Effort

1. **主规则:** `pickDefaultEffort(model)` 始终用 live `isDefault`（1.0 → high）。  
2. **静态兜底:** `DEFAULT_EFFORT` 与 `GROK_BUILD_EFFORTS[].isDefault` → **high**。  
3. **迁移:** 增加 one-shot `effortDefaultMigrated`（或等价）：仅当 effort **未设置**，或仍为**旧产品默认 medium 且从未显式选择**时抬到 high。**禁止**覆盖用户主动选的 low/medium。  
4. **连接加速文案:** 删除「默认 medium 加速」；加速手段保留 `--no-auto-update`、进程复用、openSession 预热。  
5. **Spawn:** 去掉 `matches!(e, "high"|"medium"|"low")` 硬表；改为「非空且 catalog/prefs 合法 id 则透传」。

### 决策 D-W — Workflows 默认

| 选项 | 含义 |
|------|------|
| **W1（推荐）** | 新装 / 未迁移字段 → `workflows_enabled: true`，与 CLI ≥0.2.111 默认一致；shared 模式仍不改写 `~/.grok`，仅 honesty 提示 |
| W2 | 保持 App opt-in false，只做 discoverability |

**推荐 W1：** 用户要求「完全利用」+ 「默认行为对齐」；workflows 是 1.0 Goal 驱动依赖。迁移同 effort：只抬「从未显式关过」的安装。

### 决策 D-M — Memory

保持 **默认 off** + 强制 `--no-memory`（独立模式写入 agent-home 时同步）。  
理由: 跨会话记忆涉及项目隐私；与 sandbox 产品默认「更严」同向。GUI 做齐 **dream 配置 / clear / 状态芯片**，不默认开启。

## 4. Spawn 对照（实现锚点）

权威实现: `src-tauri/src/acp_client.rs` → `spawn_with_home`  
连接入口: `session_manager/connect.rs`

```text
grok
  --no-auto-update
  [--compaction-mode|detail]   # soft ≥0.2.117
  --permission-mode <mode>
  [--sandbox PROFILE]
  [--max-turns N]
  [bg-wait flags]
  [--json-schema …]
  [--rules …] [--system-prompt-override …]
  [--disable-web-search] [--no-ask-user]
  [--tools …] [--disallowed-tools …]
  [--todo-gate] [--no-plan]
  [--agent NAME] [--agents JSON]
  [--no-subagents] [--experimental-memory|--no-memory]
  agent
  [--leader|--no-leader]
  [--agent-profile PATH]
  [--model ID]
  [--reasoning-effort <id>]    # 今日白名单过窄 ← 必改
  [--always-approve]
  [--plugin-dir …]
  stdio
```

App **从不**执行 `~/.grok/bin/agent` 作为进程入口；skew 只影响外部 TUI。

## 8. 风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| Effort→high 加长 TTFT / 费用 | 用户抱怨「变慢」 | 仅迁移旧默认；芯片可一键 low/medium；文档说明 |
| Workflows 默认 on 带来陌生 tool 行为 | 困惑 | Settings 可关；honesty 文案；shared 不强制写 ~/.grok |
| live catalog 仍标 medium default | UI 振荡 | **永远** prefer live `isDefault` |
| 500K 未进 initialize | 芯片错误 | 未知优于硬编码 |
| Ops IA 过载 | 找不到按钮 | 一个 Ops 心智；leader 进阶 |
| Goal 事件稀疏 | 面板「坏了」 | 空态诚实，不主推常驻进度条 |
| Workflow 日志靠扫 stdout | 脆弱 | 优先结构化 NDJSON / tool 事件 |
| independent/shared 写错 | 污染用户 ~/.grok | shared refuse-write 测试 |
| 外站 changelog 滞后 | 对外沟通错误 | 以本机 version + 本计划为准 |

## 9. 成功定义

在 **CLI 1.0.0** 上，用户应感到:

1. **默认**与 CLI 一致（high effort、grok-4.5、500K 窗口、workflows on）。  
2. **多会话 Ops**（tasks / dashboard / stop-all）可发现且诚实。  
3. **Goal / workflow** 有 CLI 信号才展示进度，从不伪造。  
4. **Sandbox / memory clear / dream 配置** 产品级，independent 安全。  
5. **Export / inspect / personas** 不靠手敲 CLI。  
6. **升级后版本与 symlink skew** 可见可修。  
7. **旧 CLI** 仍 soft-omit 运行，无强制升级墙。
