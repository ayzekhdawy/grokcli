## 0. Icon 指认（已校正，禁止再对调）

| 代号 | 截图形态 | 中文产品名 | 作用 |
|------|----------|------------|------|
| `open-with` | 方框+斜箭头 + `▾`，有 pill 底 | **使用指定应用打开** | 主窗口右上；全局/会话级用指定应用打开 |
| `env` | 三条横线带旋钮 `··\|·` | **环境** | 主窗口右上；点开「环境信息」下拉 |
| `dock-btm` | 方框 + 底边横线 | 底部面板 | **本期去掉**（主窗口不出现；侧栏中间位忽略） |
| `side` | 圆角竖分栏；active 有底 | **显示/隐藏侧边栏** | 收起时在主窗口；打开后在侧栏顶栏最右 |
| `expand` | 四角外扩 | 扩展侧栏 | **仅**侧栏打开时出现在侧栏顶栏；借 chat 区 |
| `plus` | `+` | 新建标签 | 贴 tab 区右侧 |
| `tree` | 文件夹轮廓 | 文件树显隐等 | 文件第 2 行 / 树折叠后角上 |
| `file-open` | 「打开」▾ | 打开当前文件 | 文件面包屑行，可带编辑器/Chrome 标 |

**禁止** 把 `open-with` 叫成 env，或把 `env` 叫成 sliders。

## 1. 主窗口右上角（开/关两态）

### 1.1 侧栏收起

```
[ open-with ▾ ]  [ env ··|· ]  [ side ⧉ ]
```

（Codex 原图还有 `dock-btm`，本期去掉。）

### 1.2 侧栏打开

```
主窗口:   [ open-with ▾ ]  [ env ··|· ]
侧栏顶栏: [ tabs… ][ + ] …… [ expand ][ side ]
```

- 打开后 **`side` 不在主窗口**，只在侧栏顶栏（可 active 底）。  
- `expand` 只在侧栏打开时出现。  
- `env` 两种状态都在主窗口、紧挨 `open-with` 右侧。

### 1.3 环境信息下拉（由 `env` 触发，image-7）

```
环境信息                              +
[⊕] 变更                  +187 -142
[💻] 本地                           ▾
[⑂] main                            ▾
[◎] 提交或推送
[🐙] 正在检查拉取请求
```

第一期：展示 + 点击带上下文开侧栏/tab；完整 git 写操作后补。

## 2. 侧栏顶栏（全 kind 共用）

```
[ 标签滚动区 ][ + ]········[ expand ][ (dock-btm 忽略) ][ side ]
```

- `+` 紧贴最后一个 tab，不贴侧栏最右。  
- 溢出横向滚动 + 被挡端黑渐变（image-3）。  
- min-width **400px**。  
- 快捷键：`⌥⌘B` 显隐侧栏；tooltip：`显示/隐藏侧边栏`。

### 2.1 空态选择（image-1，无侧边聊天）

```
文件      ⌘P
浏览器    ⌘T
终端
审阅      （仅 git 项目）
```

垂直列表，非网格。

---

## 3. 文件 / 审阅 / 类型（摘要）

- **文件**：两行 chrome（tab 行 ≠ breadcrumb 行）；**一棵树** + 多预览 tab；树可 icon 关。  
- **浏览器 / 终端**：不限数量；终端 = `$SHELL` login shell。  
- **审阅**：image-4 内层工具条；仅 git；与侧栏三控制分层。  
- **Plan**：临时 tab，仅过程创建，不可手建。  
- **侧边聊天**：不做。  
- 全类型 tab **共用**侧栏顶栏 strip。

详见 `IMPLEMENTATION.md`。
