## 1. 一句话定位

**Grok App = 本机 Grok Build 的桌面指挥台**（对标 Codex Desktop / Claude Desktop 的「本地 Agent 壳」）。

- 主价值：用图形界面管理**项目、会话、模型、权限、中转账号**，稳定跑 Grok Build 写代码。
- 不是：本地 API 网关（那是 [grok-go](https://github.com/RongleCat/grok-go)）；不是 IM 桥（那是 agent-connect）。

| 产品 | 角色 |
|------|------|
| **Grok App** | 桌面 Agent IDE 壳：对话 + 工具 + 权限 + 会话 |
| **grok-go** | 本地中转 / 账号网关，可被本 App **导入配置** 后当 Provider |
| **agent-connect** | 飞书等 IM ↔ Agent，**本产品不做** |
| **Grok Build CLI** | 实际干活的 Agent 运行时（本 App 通过 ACP 驱动它） |

**品牌说明：** MIT 开源社区客户端，**非 xAI 官方**；README / 关于页必须写明。作者 X：[cgnot996](https://x.com/cgnot996)；与 grok-go 为姐妹项目。

---

## 2. 目标用户

1. **个人开发者**：已在用 Grok Build CLI，想要更好的会话管理与可视化。  
2. **中转用户**：自建 / 购买 OpenAI 兼容中转，需要在桌面里配 Key、选模型、测连通。  
3. **多项目并行**：同时开 2～3 个代码仓库会话，不互相串。

首版不主打：团队协作、云端 farm、企业 SSO、教学演示。

## 3. 范围与分期

### 3.1 MVP / P0（必须能日用）

| 模块 | 必须有 |
|------|--------|
| 安装与运行时 | 安装包启动 → 检测 Grok Build → 缺失则引导/自动安装最新版 |
| 账户 | 官方登录或 API Key；**自定义 OpenAI 兼容中转**；连通测试 |
| 配置导入 | 一键导入 **grok-go** / 本机已有 CLI 配置（Key / Base URL，不明文回显） |
| 项目 | 添加本地目录、信任确认、最近打开 |
| 会话 | 新建 / 继续 / 重命名 / 删除 / 搜索；多项目多会话；**独立 / 共通**数据模式（默认独立） |
| 对话 | 流式输出、思考折叠、工具步骤折叠、停止生成、附件/图片 |
| 控制条 | 模型、reasoning effort、权限（**Ask 默认** / Allow once / Allow for session / Deny；全局 Always 仅设置深层） |
| 设置 | 主题明暗、中英语言、Agent 路径、会话数据模式、关于与版本 |
| 诊断 | **Doctor**：CLI 是否找到、鉴权、Provider ping、日志路径 |
| 壳 | 无边框 + 圆角；mac 交通灯 / Win 自绘按钮；暗色 + 亮色完整覆盖 |

### 3.2 P1（日用后增强，设计期预留 UI 位）

- 会话 fork / rewind / compact / 导出 Markdown  
- MCP / Skills / Plugins 管理页  
- Plan / Goal 状态条、Subagent / 后台任务面板  
- Diff 面板、在外部编辑器打开文件  
- 系统托盘、自动更新（Tauri updater）  
- 会话上下文用量 chip  

### 3.3 P2 / 明确非目标（首版不做）

| 不做 | 原因 |
|------|------|
| 飞书 / 钉钉 / 企业微信桥 | 由 agent-connect 负责 |
| 内嵌完整终端 | 成本高，非主路径 |
| 云端 multi-agent farm、best-of-n | 范围过大 |
| `/share` 公网分享 | 安全与合规成本 |
| Hooks 完整可视化管理 | 低频，可后置 |
| Linux 首发 | 仅 **macOS + Windows** 首发 |
| 默认「YOLO 全自动」权限 | 安全默认值必须保守 |

## 4. 架构默认方案（可直接执行）

### 4.1 Agent 接入：ACP 主路径

| 方式 | 结论 |
|------|------|
| **`grok agent` stdio + ACP（JSON-RPC）** | **主路径**。持久会话、权限、工具流、plan/goal 都靠它 |
| `grok -p` / 一次性 prompt | 仅脚本 / 诊断 / 特殊一次性任务，**不做主循环** |
| `agent serve` 远程附着 | **MVP 不做** |

### 4.2 进程模型

- **每个活跃会话 Thread 对应一个 Agent 子进程**。  
- 默认最多 **3** 个同时活跃 Agent 进程；超出提示用户或排队。  
- 空闲 **30 分钟** 可回收进程（会话元数据保留，下次自动再附着）。  
- 崩溃：UI 显示「会话断开」，提供「重新附着」；禁止把「鉴权失败」标成「CLI 未找到」。

### 4.3 数据目录与会话模式（D2）

配置键：`session_data_mode = "independent" | "shared"`，**默认 `independent`**。

| 模式 | 数据根 | 行为 |
|------|--------|------|
| **independent（默认）** | `~/.grok-app`（Windows：`%APPDATA%\grok-app`） | 会话历史与 CLI 隔离；可**导入** CLI/grok-go 配置（账号、供应商），不共享会话文件 |
| **shared** | CLI 主目录（默认 `~/.grok`，尊重 `GROK_HOME` 若有） | App 与 CLI 共用会话列表/历史；必须有文件锁与并发策略；切换模式时**强制提示**数据位置差异 |

约束：

1. **导入配置 ≠ 会话共通**（D5 的 grok-go 导入只拷贝供应商/账号）。  
2. **禁止**无提示跨模式混读。  
3. 密钥：OS 安全存储（macOS Keychain / Windows Credential Manager）；日志 **强制 redact**。

### 4.4 Agent 二进制（D3）

1. 探测 PATH / 常见安装路径  
2. 无则：**用户确认后**自动下载官方最新 Grok Build  
3. 设置页可手动指定路径 + Doctor 验证  
4. **不内嵌** agent 到安装包  

### 4.5 与 grok-go 联动

- **导入** Base URL、API Key、默认模型（只读对方配置目录，不反向改写 grok-go）。  
- 可选：一键「把 grok-go 本地地址加成 Provider」。  
- **不做** 在 App 内嵌完整 grok-go 网关 UI。

### 4.6 账户双通道（D5）

Onboarding **并列三入口**：「登录官方」/「配置中转」/「从 grok-go 导入」。

1. **官方通道**：OAuth / device code / 官方 API Key（跟 Grok Build 一致）。  
2. **自定义中转**：OpenAI 兼容 `base_url` + key + 模型列表拉取 + Ping。  
3. 两通道配置隔离；会话内可切换默认模型。

### 4.7 技术栈

- **Tauri 2 + React + TypeScript**（与 grok-go 生态一致）。  
- 前端：会话列表虚拟滚动；流式只更新内存，**落盘节流**。  
- Host：Rust 负责 spawn ACP、密钥、文件系统沙箱边界。

## 7. 性能与稳定性（硬指标）

| 项 | 默认指标 |
|----|----------|
| 冷启动到可输入 | mac 目标 ≤ 3s（已装好 CLI、已登录） |
| 会话落盘 | **批量写**；流式过程中不每 token 刷盘；≥ 500ms 或段落边界节流 |
| 历史列表 | 虚拟列表；大 transcript 窗口加载 |
| 活跃 Agent | 默认上限 3；闲置回收 |
| 空闲内存 | 无活跃会话时尽量 < 300MB（发版前实测校准） |
| 流式空闲 | 长时间无 chunk 提示「仍在运行 / 可能卡住」，可取消 |

**禁止**：每个 token 同步写盘导致磁盘/风扇尖刺。

---

## 8. 安全与合规

- 默认权限：**需确认**写文件 / 跑命令（非 YOLO）。  
- 打开项目前 **信任目录** 确认。  
- 危险命令二次确认（若底层 Agent 支持透传）。  
- 遥测：**默认关闭**；若以后加，必须 opt-in。  
- MIT 开源；关于页注明非官方。

## 10. 设计期避坑清单

1. CLI 多路径探测 + 手动指定 + Doctor，禁止只报「unknown error」  
2. Provider 错误分类：401 / 404 模型不存在 / 超时 ≠ CLI_NOT_FOUND  
3. 拖拽：文件引用 vs 图片上传分流  
4. 流式超时与可取消  
5. 第三方模型不支持的 effort 要 UI 降级，不要静默失败  
6. 配置正确但 spawn 失败 → 独立诊断路径  
7. i18n 覆盖错误文案  
8. mac「已损坏」→ 文档写清公证 / `xattr` 说明  

---

## 11. 验收标准（MVP 发布门槛）

1. 全新机器：安装 App →（自动/引导）装好 Grok Build → 登录或配中转 → 打开项目 → 完成一轮对话含工具调用。  
2. 双项目双会话互不串消息 / 互不写错目录。  
3. 断网 / 错误 Key / CLI 被删：Doctor 能指出正确原因。  
4. 明暗主题全页面切换无「漏白 / 漏黑」组件。  
5. 流式 5 分钟对话磁盘写入无异常尖刺。  
6. 密钥不出现在日志文件中。  
7. 从 grok-go 导入配置后可成功对话。  
8. `session_data_mode` 默认独立；切到共通有明确提示且不混读历史。  

详细勾选见 [`P0-能力矩阵.md`](./P0-能力矩阵.md)。
